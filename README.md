# 🌿 Plant Disease Detection System

An AI-powered web application that detects plant diseases from leaf images using a fine-tuned **MobileNetV2** deep learning model trained on the **PlantVillage** dataset.

---

## 🚀 Features

- **38 Disease Classes** across 14 plant species (Tomato, Corn, Apple, Grape, Potato, and more)
- **97%+ Accuracy** using MobileNetV2 transfer learning + fine-tuning
- **Treatment Recommendations** for each detected disease
- **Severity Ratings** (None / Moderate / High / Critical)
- **Drag-and-Drop Web UI** — fully local, no cloud required
- **Top-3 Predictions** with confidence bars

## ⚙️ Setup & Installation

### Prerequisites
- Python 3.9–3.11
- pip
- ~4 GB disk space (for TensorFlow + model)
- GPU optional but recommended for training

### Step 1: Create a Virtual Environment

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Download Dataset

Download the **PlantVillage** dataset from Kaggle:  
🔗 https://www.kaggle.com/datasets/emmarex/plantdisease

Extract it so the folder structure looks like:
```
PlantVillage/
├── Apple___Apple_scab/
├── Apple___Black_rot/
├── Tomato___Late_blight/
...
```

### Step 4: Train the Model

```bash
python scripts/train_model.py --data_dir /path/to/PlantVillage --epochs 20
```

The trained model will be saved to `model/plant_disease_model.h5`.

**Expected Training Time:**
| Hardware | Time |
|---|---|
| NVIDIA GPU (RTX 3060+) | ~25–40 min |
| Apple M1/M2 | ~60–90 min |
| CPU only | ~3–5 hours |

### Step 5: Evaluate the Model (Optional)

```bash
python scripts/evaluate_model.py --data_dir /path/to/PlantVillage
```
This generates a confusion matrix and classification report in the `model/` folder.

### Step 6: Run the Web Application

```bash
python app.py
```

Open your browser and go to: **http://localhost:5000**

## 🖼️ How to Use

1. Open http://localhost:5000 in your browser
2. Drag-and-drop a leaf image or click to browse
3. Click **Analyze Leaf**
4. View the detected disease, confidence score, severity, and treatment recommendations

## 🔧 Technical Details

| Component | Details |
|---|---|
| Base Model | MobileNetV2 (ImageNet pre-trained) |
| Input Size | 224 × 224 × 3 |
| Output | 38-class softmax |
| Optimizer | Adam (lr=1e-4, fine-tune lr=1e-5) |
| Data Augmentation | Rotation, flip, zoom, brightness |
| Framework | TensorFlow 2.16 / Keras |
| Web Framework | Flask 3.0 |
